# 🚀 DevPulse API (Assignment-02)

A RESTful API built with **Node.js, Express, TypeScript, and PostgreSQL** for managing issues with authentication and role-based authorization.

---

## 🔗 Live URL

👉 https://assignment-02-devpulse.vercel.app/

---

## 📌 Features

- 🔐 JWT Authentication (Signup & Login)
- 👤 Role-based Access Control (Contributor)
- 📝 Create, Read, Update, Delete Issues
- 🔎 Sort Issues (Newest / Oldest)
- ⚡ Error Handling Middleware
- 🧱 Clean Modular Architecture

---

## 🛠️ Tech Stack

- Node.js
- Express.js
- TypeScript
- PostgreSQL
- JWT (jsonwebtoken)
- bcrypt
- Vercel (Deployment)
